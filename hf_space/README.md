# FRAME · AI-модули

Демо ИИ-слоя платформы FRAME для конкурса Junior ML Contest.

- **Анализ сметы** — модель сравнивает каждую позицию с реальными рыночными ценами (2108 цен, 22 компании, 7 городов) и помечает завышения.
- **Рейтинг мастера по отзывам** — нейросеть раскладывает отзывы на 9 аспектов (сроки, качество, цена, чистота, коммуникация, профессионализм, честность, гарантия, вежливость).

Данные собраны вручную скраперами с публичных прайс-листов и площадок отзывов.

Исходный код: https://github.com/verbitskiyartemiy/frame-smeta-ai
